      想出 PDF？拿这本 EPUB 去转换

      生成的 EPUB 带完整元数据（书名 / 作者 / 目录 / 语言），可直接导入 Apple Books、微信读书（导入本地书）、Calibre 等阅读器。想把排版再精一步， 在本机跑 SEES PRESS 的完整管线。

      书名和作者是怎么识别的？

      优先取文首 --- 元信息里的 title / author；没有就取正文第一个一级标题当书名。 作者识别不出就留空，可手动填写。文件名不会当书名用。

      图片怎么办？

      相对路径的本地图片没法从 Markdown 里读出，会被替换成「〔图：说明〕」占位并在上方提示； 网络图片与 data URI 会原样保留。要带插图出书，请用本机 SEES PRESS 完整管线或 PDF → EPUB。

      章节切分为什么有时找不到？

      切分只认行首的 # / ##（代码块里的不算）。全文只有一个一级标题时自动 退到二级标题；一个标题都没有就整本一章。切分粒度随时可以手动指定。

      和 PDF → EPUB 有什么不同？

      那份是把版面式的 PDF「拆回」结构化文本；这份是从结构化文本「装成」电子书—— 顺序相反，入口不同。常见的完整链路是：Markdown 排成 EPUB，再送 EPUB → PDF 出打印稿。
