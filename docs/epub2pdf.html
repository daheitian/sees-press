EPUB → PDF

把 EPUB 重排成可以打印的版面

EPUB 是流式排版，本身没有固定页面。这里按你选定的纸张与字号重新排版、分页， 再交给系统打印成 PDF。文件不上传，解析与排版都在本机浏览器里完成。

纯本地处理 · 无服务器 · 不上传任何文件

支持 EPUB 2 / EPUB 3。会按 OPF 的 spine 顺序重排，保留章节、插图与表格。

    打印对话框里若勾选「页眉和页脚」会带上页码与标题；不想要就在那里取消。 版面是按连续的流重排的，跨页处与原书不会逐页对应——这是重排的代价，也是它清晰的原因。

    为什么是在浏览器里打印，而不是直接下载一个 PDF？

    浏览器里没有 LaTeX 这类排版引擎，能做的是「用 CSS 分页规则重排 + 交给系统打印」。好处是零依赖、不上传、 任何机器都能用；代价是数学公式、复杂表格和脚注悬挂达不到 TeX 成品的精度。要出版级精度， 请在本机的 SEES PRESS 里用 XeLaTeX 那条支线出 PDF。

    页码为什么不在正文里？

    CSS 的页边页码在 Chrome 里不支持。请用打印对话框自带的页眉页脚，或在系统打印设置里开页码。

    原书的字体和版式会保留吗？

    不会，这里是有意重排：统一字体、行距、段首缩进，让不同来源的 EPUB 印出来气质一致。 原书封面与插图会保留。
